* Online Purchase Cost Calculator

*Overview

-This is an Android app that calculates the total cost of an online purchase. The total cost includes the price of the item, 
optional warranty and insurance, and delivery charges. The app is built using XML for UI design and Java for backend logic in Android Studio.

*Features

-User Input for Price: Enter the base price of the product.

-Toggle Button for Warranty: Adds 10% of the price if enabled.

-Switch for Insurance: Adds 5% of the price if enabled.

-Spinner for Delivery Options: Select between normal ($5), second-day ($10), and next-day ($20) delivery.

-Submit Button: Calculates the total cost when clicked.

-Displays the Final Total Cost.

*Technologies Used

-Android Studio: IDE for development.

-Java: Programming language for logic implementation.

-XML: For UI design.

-Model-View-Controller (MVC) Architecture.

*App Structure

1-Model: Handles the business logic of calculating the total cost.

2-View (XML Layout): Displays UI components.

3-Controller (Java Activity Class): Manages user interactions and updates UI accordingly.

*How It Works

-Enter the price of the product in the input field.

-Toggle the warranty button if you want a warranty (adds 10%).

-Enable the insurance switch if you want insurance (adds 5%).

-Choose a delivery option from the spinner.

-Click the "Submit" button to calculate the total cost.

-The total cost is displayed on the screen.

*Event Handling

-The Submit button is handled using a Listener Interface to ensure proper interaction.

-UI/UX Considerations

-Linear Layout for a simple and structured UI.

-Proper spacing and padding for better readability.

-User-friendly colors and fonts.

*How to Run the Project

-Open Android Studio.

-Load the project files.

-Connect an emulator or physical device.

-Click Run to install and test the app.
